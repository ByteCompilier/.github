### 🚀 About the Project

We build fast, lightweight developer tools with zero bloat. Our flagship project is **ByteC** — a clean, compiled programming language paired with **BPM (ByteC Package Manager)**, an automated, security-audited package registry.

### 💻 Quick Example

Get started in seconds — initialize a workspace, install libraries from the registry, and compile:

```cmd
:: Initialize a new ByteC project
bpm init

:: Install standard and community packages
bpm install std add

:: List installed packages
bpm list
```
